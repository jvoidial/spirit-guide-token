# Privacy Policy

**Project:** PHB Dashboard
**Maintainer:** VOIDBOT0

## 1. What Data This Interface Collects

**None.**

This dashboard is a static, client-side interface. It does not:
- Use cookies for tracking
- Use analytics scripts
- Collect personal data
- Store user information
- Track user behavior

## 2. Third-Party APIs

The dashboard fetches public data from third-party APIs including GeckoTerminal, DexScreener, and DeFiLlama. These requests are made directly from your browser to those services. Their privacy policies apply.

## 3. Blockchain Data

Blockchain data is public by nature. Your wallet address and transactions are visible on-chain. This is not controlled by this project.

## 4. GDPR

Because no personal data is collected by this interface, no GDPR obligations arise from its use. If you believe your data has been processed in error, contact the maintainer.

## 5. Contact

For privacy concerns: open an issue on the GitHub repository.
